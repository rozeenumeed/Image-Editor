# 🎨 Image Editor

A simple and interactive **Image Editor** built using HTML, CSS, and JavaScript. This project allows users to upload images, apply different visual filters, choose creative presets, reset changes, and download their edited images.

## ✨ Features

- **Image Upload:** Upload an image from your local device.
- **Brightness:** Adjust the brightness of an image.
- **Contrast:** Increase or decrease image contrast.
- **Saturation:** Control the intensity of colors.
- **Hue Rotation:** Change the color tones of an image.
- **Blur:** Apply a blur effect.
- **Grayscale:** Convert images to black and white.
- **Sepia:** Apply a vintage-style effect.
- **Opacity:** Adjust image transparency.
- **Invert:** Create a negative color effect.
- **Presets:** Apply predefined effects with a single click.
- **Reset Filters:** Restore the default filter values.
- **Download Image:** Save the edited image as a PNG file.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Canvas API

## 🚀 Getting Started

### 1. Clone the Repository

git clone YOUR_REPOSITORY_URL

Replace `YOUR_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Open the Project

Navigate to the project folder and open `index.html` in your web browser.

You can also use the **Live Server** extension in Visual Studio Code for a better development experience.

### 3. Start Editing

1. Upload an image.
2. Adjust the available filters using the sliders.
3. Choose a preset to apply a predefined effect.
4. Use the Reset button to restore the default settings.
5. Click Download to save your edited image.
